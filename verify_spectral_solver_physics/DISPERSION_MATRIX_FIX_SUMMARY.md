# Dispersion Matrix Sign Error Fix - Summary

## Problem Statement

The numerical Israel-Stewart hydrodynamics solver was underpredicting sound wave damping by **87%** compared to analytical predictions from the dispersion relation.

## Root Cause

Two **compensating sign errors** in the analytical dispersion matrix used to compute eigenmode frequencies and attenuation rates:

### Bug 1: Momentum Equation (Row 1, Column 3)
**Incorrect**: `matrix[1, 3] = +1j * k` (positive sign)
**Correct**: `matrix[1, 3] = -1j * k` (negative sign)

**Physical Interpretation**: Shear stress δπ_xx acts like pressure and pushes back on the fluid. Its contribution to the momentum equation should be **-ik·δπ_xx**, not +ik·δπ_xx.

### Bug 2: Shear Relaxation Equation (Row 3, Column 1)
**Incorrect**: `matrix[3, 1] = +1j * (4/3) * eta * k` (positive sign)
**Correct**: `matrix[3, 1] = -1j * (4/3) * eta * k` (negative sign)

**Physical Interpretation**: Shear stress δπ_xx is generated by velocity gradients. The correct linearized Israel-Stewart equation is:
```
τ_π Dπ^μν/Dτ + π^μν = 2ησ^μν
```
For 1D plane wave: σ_xx = (2/3)ik·δv_x

This gives: (1 - iωτ_π)δπ_xx = (4/3)ηik·δv_x

Rearranging: **-(4/3)ηik·δv_x** + (1 - iωτ_π)δπ_xx = 0

The velocity gradient term must have a **negative sign**.

## Compensating Errors

These two bugs masked each other:
- Bug 1: Wrong sign in how shear affects momentum
- Bug 2: Wrong sign in how velocity generates shear

Together, they produced a partially correct dispersion relation that still found roots, but with incorrect eigenmode structure. This led to:
1. **Acausal high-frequency mode** (ω ≈ 6.0) appearing as the primary root
2. **87% underprediction** of damping rate when simulating sound waves
3. **Phantom roots** in the dispersion relation

## Fix Implementation

**File**: `israel_stewart/benchmarks/sound_waves.py`

**Lines 417-432** (corrected dispersion matrix):
```python
# Row 1: Momentum conservation ∂_μ T^μx = 0
# ik·c_s²·δε - iω·(ε₀+p₀)·δv_x + ik·δΠ + ik·δπ_xx = 0
matrix[1, 0] = 1j * k * cs_squared  # δε coefficient
matrix[1, 1] = -1j * omega * enthalpy  # δv_x coefficient
matrix[1, 2] = 1j * k  # δΠ coefficient
matrix[1, 3] = -1j * k  # δπ_xx coefficient ✓ FIXED: negative sign

# Row 3: Shear stress relaxation equation
# (1 - iωτ_π)·δπ_xx - i·(4/3)ηk·δv_x = 0
matrix[3, 1] = -1j * (4.0 / 3.0) * eta * k  # δv_x coefficient ✓ FIXED: negative sign
matrix[3, 3] = 1.0 - 1j * omega * tau_pi  # δπ_xx coefficient
```

## Related Bugs Fixed

During this investigation, two additional bugs were found and fixed:

### 1. Four-Velocity Normalization in RK4 (spectral.py:1977)
**Problem**: Spatial velocity u^i was updated but u^0 wasn't recalculated, violating u^μ u_μ = -1.

**Fix**: Added `self.fields.normalize_four_velocity()` call after field updates.

### 2. Double-Counting of Linear Relaxation (spectral.py:1884-1927)
**Problem**: Split-step method applied linear relaxation term -Π/τ multiple times.

**Fix**: Implemented `_advance_relaxation_sources_only()` method that excludes linear terms already handled by spectral integrators.
